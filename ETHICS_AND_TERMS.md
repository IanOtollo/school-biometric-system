# Ethics and Terms of Service

## The Ethical Formula
**Safety + Privacy + Consent = Ethical Biometric Integrity**

The School Biometric System is designed to enhance campus security while strictly adhering to ethical standards of data protection and individual privacy.

## 1. Purpose of the System
The primary purpose is to regulate and monitor access to school premises, ensuring that only authorized individuals and registered visitors enter the campus.

## 2. Data Collection and Consent
- **Voluntary Enrollment**: Enrollment in the biometric system is based on informed consent.
- **Minimal Data Collection**: Only necessary descriptors and identification details are stored.
- **Purpose Limitation**: Data collected will NOT be used for any purpose other than access control and security monitoring.

## 3. Privacy and Data Security
- **Encryption**: Biometric descriptors are stored using secure mathematical representations.
- **Restricted Access**: Only authorized administrative personnel (Security/Admin) can view sensitive data.
- **No Data Deletion WITHOUT Preservation**: Person details are maintained for historical search and security referencing even if their status changes, unless a formal deletion request is processed.

## 4. Individual Rights
- Individuals have the right to know what data is being held about them.
- Individuals can request corrections to their data through the Admin department.

## 5. System Integrity
- The system must not be used for discriminatory practices.
- Automated decisions (Access Granted/Denied) can be manually overridden by security personnel in case of system error or special circumstances.
